# From Observation to Intervention: A Causal Audit of Expert Importance in Mixture-of-Experts Models

**会议**: ICML2026  
**arXiv**: [2606.10703](https://arxiv.org/abs/2606.10703)  
**代码**: https://github.com/callmeloui/observational_metrics  
**领域**: 因果推断 / 机制可解释性  
**关键词**: MoE 剪枝, 因果审计, 干预性证据, 专家重要性, 路由统计量

## 一句话总结
作者用「逐 token 消融」的干预性审计去检验 MoE 剪枝里「观测性路由统计量能预测哪些专家可删」这一隐含假设，在三个高冗余 MoE 模型上得到一个干净的「三模型零结果」：60 个指标-层组合里没有任何观测指标在多重比较校正后能预测专家的因果重要性，说明现有剪枝方法之所以有效，不是因为指标真挑出了「没用的专家」，而是因为早中层的冗余让几乎任何选择准则都同样安全。

## 研究背景与动机
**领域现状**：可解释性方法有一个非常普遍但很少被审视的推理动作——拿「在观测到的模型行为上算出来的统计量」去预言「如果做一次有针对性的干预会发生什么」。注意力权重被读成对单条预测的解释，梯度显著性被读成「删掉这些输入会改变输出」，而 MoE 里的路由统计量（利用率、激活范数、路由权重分布）则被读成「这些专家被路由得少 / 不重要，删了不影响功能」。

**现有痛点**：用 Pearl 的因果阶梯来说，这是把第一层（rung-1，关联性证据）当成第二层（rung-2，干预性结论）在用。这个从「观测」到「干预」的跳跃，其有效性几乎从没被正面测过；而每次被测时往往就翻车了——Jain & Wallace (2019) 证明注意力权重预测不了扰动输入的效果，Adebayo et al. (2020) 证明显著性图在随机化模型权重后依然「存活」。MoE 剪枝文献正建立在同一个未经检验的代理假设上：按某个观测准则给专家排序 → 删掉排名最低的 → 微调恢复能力。

**核心矛盾**：「专家被路由得更频繁 / 更集中 = 它做的工作更重要」这个直觉是**群体层面（population-level）**的平均统计，而剪枝真正关心的「删掉这个专家会不会改变模型在某个具体 token 上的预测」是**token 层面（token-level）**的因果问题。前者根本不保证后者成立。

**本文目标**：把这个抽象的「观测→干预」鸿沟落到一个具体、可操作、可证伪的实例上——MoE 专家剪枝，并给出明确的反例。

**切入角度**：既然「观测指标排序能预测哪个专家的消融真的改变行为」是个因果命题，那就直接用**干预**（消融）去测它，而不是再算一个观测相关性。

**核心 idea**：在 token 层面做配对消融审计——同一个 token 上，把指标排名最高的专家消融、再把排名最低的消融，看二者造成的损失变化之差是否可靠为正；如果群体统计量真有效，这个差应该系统性地大于零。

## 方法详解

### 整体框架
这不是一篇提方法的论文，而是一篇**审计**论文：它要解决的问题是「观测性路由统计量到底有没有资格预言专家消融的因果后果」，整体做法是把这个问题翻译成一个可统计检验的逐 token 实验，然后在三个跨越当代 MoE 主要设计维度的模型上跑同一套机器。

流程是：对每个「指标-层-模型」组合，采样 $n=200$ 个 token 位置；在每个位置上确定当前被激活的路由专家集合 $\mathcal{A}_t$，按目标指标排序，分别消融排名最高和最低的专家，记录各自造成的损失变化 $\Delta\mathcal{L}_i^{(t)}=\mathcal{L}_t^{(-i)}-\mathcal{L}_t$（其中 $\mathcal{L}_t=-\log p_\theta(x_{t+1}\mid x_{\le t})$）；用配对 $t$ 检验（Cohen's $d$ 作效应量）加 Wilcoxon 符号秩检验交叉验证；最后对所有组合做 Bonferroni 多重比较校正。一旦观测指标全军覆没，再用一个「按 token 条件化的路由权重」作为对照实验，确认零结果不是统计功效不足造成的。

### 关键设计

**1. 逐 token 干预审计协议：把「指标有效」写成一个可证伪的因果命题**

痛点在于：以往文献说「利用率低的专家可删」时，从没把这句话变成一个能被实验否定的断言。作者给出 Definition 2.1（指标的因果有效性）：观测指标 $m$ 在 token 层面**因果有效**，当且仅当在 token 位置 $t$ 的激活专家集 $\mathcal{A}_t$ 中，更高的 $m(e)$ 能预测更大的功能重要性 $\Delta\mathcal{L}_e^{(t)}$。这把「能不能用 $m$ 选专家剪枝」精确化为「删低 $m$ 的专家应该优先删到低重要性的专家」。具体检验上，有效性等价于配对差 $\Delta\mathcal{L}_\text{high}-\Delta\mathcal{L}_\text{low}$ 可靠为正。

这里区分了两个量：**功能重要性** $\Delta\mathcal{L}$ 问「消融是否改变了模型在该 token 的预测」；**gap norm** $\delta_i^{(t)}=\lVert\mathbf{y}_t-\mathbf{y}_t^{(-i)}\rVert_2$ 问「消融是否改变了残差流，不管这个改变有没有传到输出」。后者后面用来诊断 OLMoE 末层异常。共享专家（Qwen、DeepSeek 里有）在审计中**永不修改**，只动路由专家。

**2. 路由权重对照实验：排除「零结果是因为功效不足」**

一个干净的零结果最大的威胁是——会不会只是实验没力气检测到本来就存在的弱信号？作者用**完全相同的机器**（同样的 $n$、同样的配对消融、同样的检验）把观测指标换成**逐 token 的路由权重** $g_i(\mathbf{x}_t)$。注意这个量和「群体平均路由权重」那个观测指标有本质区别：它是按当前 token 条件化的，代表任何路由派生量在原则上能拿到的预测信号上界。

如果这套机器连一个信号都找不到，那才是功效问题；但实验恰恰**找到了**一个 Bonferroni 显著的信号（OLMoE 末层），证明协议有足够功效——观测指标的零结果是真零，不是没力气。这一步是整篇论文方法论上最关键的「阴性对照」。

**3. 渐进式消融：直接确认「冗余区」才是现有剪枝方法奏效的真原因**

如果观测指标根本没挑出可删专家，那为什么文献报告的剪枝方法又确实有效？作者用渐进式消融给出机制性解释：在 OLMoE 上，于目标层移除权重最高的 $k$ 个激活专家，记录累计损失变化（每个 layer-$k$ 格 $n=500$ 个 token，$k\in\{1,\dots,7\}$）。结果显示第 0–9 层即使 $k=7$（八个激活专家删掉七个）平均损失变化仍 $<+0.083$ nats，而第 15 层在 $k=2$ 就「断裂」（$\Delta\mathcal{L}=+0.155$ nats），到 $k=7$ 达 $+0.431$。

$$
\text{早中层：}\;\Delta\mathcal{L}(k{=}7)<0.083\ \text{nats}\quad\text{vs}\quad\text{末层：}\;\Delta\mathcal{L}(k{=}2)=0.155\ \text{nats}
$$

结论很硬：早中层存在一个**冗余缓冲区**，几乎任何选择准则在这里删专家都「看起来无害」，因为这里几乎所有选择本来就无害——指标和随机基线做的是同一件事。这解释了为什么观测指标的零结果与文献报告的剪枝增益**并不矛盾**。

## 实验关键数据

### 主实验
三个高冗余 MoE 语言模型，每个审计 4 个指标 × 5 个代表性层 = 20 个组合，共 60 个组合。Bonferroni 校正：审计 $\alpha_\text{adj}=0.05/20=0.0025$，对照 $\alpha_\text{adj}=0.05/5=0.01$。语料为 WikiText-2 测试集。

| 模型 | 架构要点 | 观测指标审计结果 | 路由权重对照 |
|------|----------|------------------|--------------|
| OLMoE-1B-7B-0924 | 16 层 / 64 专家 / top-8 / 无共享 | 20 格全部不显著；唯一 $p_t{=}0.048$ 的格（L11 std, $d{=}{+}0.141$）在 L15 反号（$d{=}{-}0.020$） | **L15 $d{=}{+}0.231,\ p{=}0.0013$，全实验唯一过校正** |
| Qwen1.5-MoE-A2.7B | 24 层 / 60 路由+1 共享 / top-4 | 一格过未校正阈值但 Wilcoxon 失败（$p_W{=}0.036$），判为噪声 | $\lvert d\rvert\le0.124$，无深度集中 |
| DeepSeek-V2-Lite | 27 层 / 64 路由+2 共享 / top-6 | 三格 $p_t{<}0.05$，仅一格过 Wilcoxon（L20 利用率 $d{=}{+}0.163$） | $\lvert d\rvert\le0.098$ |

核心结论：60 个组合里**没有一个观测指标过 Bonferroni 校正**，效应量全程 $<$ Cohen's $d=0.17$，且符号在层间不一致（这正是零分布而非弱真信号的特征）。被 Jaiswal et al. (2025) 评为 16 个专家丢弃准则中最强的「激活范数」，在每个模型每个层都 $\lvert d\rvert\le0.157$，处处不显著。

### 消融 / 机制分析

| 配置 | 关键现象 | 说明 |
|------|----------|------|
| 渐进消融 L0–L9 | $k{=}7$ 时 $\Delta\mathcal{L}<+0.083$ nats | 删 8 选 7 仍功能可容忍 → 冗余缓冲区 |
| 渐进消融 L15 | $k{=}2$ 断裂、$k{=}7$ 达 $+0.431$ nats | 末层无冗余，专家真有用 |
| gap norm 随深度 | L0 的 $0.0041$ → L15 的 $0.1697$ | 残差流位移放大 $41\times$ |
| Qwen 对照 | gap norm 同样放大但无功能集中 | 排除「残差流增长」作为充分解释 |

### 关键发现
- **三模型零结果是普适的**：跨越当代 MoE 主要设计维度（单/多目标负载均衡、top-$k$ 比例 6.7%–12.5%、从零训练 vs 稠密上采样、有无共享专家），没有任何指标-层格在校正后显著。
- **OLMoE 末层效应是狭窄的**：仅一个模型、一个层、且只在直接 token 级条件化下出现；它是「存在一个逐 token 预测器」的存在性证明，**不是**任何可部署指标有效的证据（因为 $g_i(\mathbf{x}_t)$ 需要前向到该层该 token 才能算）。
- Qwen 有同等 gap-norm 放大却没有 OLMoE 的功能集中，说明残差流增长不足以解释末层效应；三个架构不足以把这个现象归因到任何单一训练/架构因素，作者把它当作需要架构内受控跟进的经验规律。

## 亮点与洞察
- **把抽象方法论批判变成可证伪实验**：Joshi et al. (2026) 的「可解释性主张需要干预性证据」是个一般论断，本文把它在 MoE 剪枝这一具体场景做实，给出了和注意力、显著性并列的「第三个反例」，非常具有教学价值。
- **阴性对照设计教科书级**：用同一套机器、同样的 $n$ 把观测指标换成逐 token 路由权重，既排除功效不足、又顺手挖出唯一真信号——一个动作同时回答了「零结果可信吗」和「到底什么样的量才有预测力」两个问题。
- **「指标和随机基线做同一件事」的洞察可迁移**：任何在高冗余子结构上做选择性删除的工作（不止 MoE，也包括通道剪枝、头剪枝）都该警惕——报告的增益可能来自冗余缓冲区而非选择准则本身，应当补一个随机基线对照。

## 局限与展望
- **作者承认**：三个架构不足以把 OLMoE 末层效应归因到任何单一因素，需要架构内受控的 checkpoint 变化跟进。
- 审计是 token 级的单专家消融，不直接等价于「先删一批专家再整体微调」的部署管线——本文明确声明它**没有**证明指标引导的剪枝作为部署流程会失败，只证明当它成功时成功不归功于指标识别了 token 级重要专家。
- 逐 token 路由权重虽是有效预测器，但需要前向到该层该 token 才能算，无法在推理前预计算，因此不能直接当作可部署的剪枝指标——「存在可预测信号」与「存在可部署指标」之间仍有距离。
- 改进方向：把审计扩展到多专家联合消融、跨更多架构（尤其是上采样训练的模型）做受控对比，以及把同样的「观测→干预」审计推广到注意力头、神经元等其他可解释性单元。

## 相关工作与启发
- **vs Jain & Wallace (2019) / Adebayo et al. (2020)**：他们分别在注意力、显著性上证明观测统计预测不了干预效果；本文在 MoE 路由统计上补了一个新的经验实例，方法论同源（用干预测关联）。
- **vs Jaiswal et al. (2025) 等剪枝方法**：他们用激活范数等观测准则给专家排序并报告剪枝增益；本文不否认增益，但指出增益来自早中层冗余而非指标的因果识别力，激活范数在 token 级处处不显著。
- **vs Joshi et al. (2026)**：他们提出「可解释性主张要泛化就需要干预性证据」的一般论断；本文把这个论断在 MoE 剪枝里落成具体的、带统计校正的反例。

## 评分
- 新颖性: ⭐⭐⭐⭐ 不是新方法而是新审计范式，把抽象因果批判落到可证伪实验，视角扎实
- 实验充分度: ⭐⭐⭐⭐ 三模型 60 组合 + 阴性对照 + 渐进消融，统计严谨；但仅三个架构、单专家消融
- 写作质量: ⭐⭐⭐⭐⭐ 「两个发现、两个尺度」的论证结构清晰，对零结果的边界声明非常克制诚实
- 价值: ⭐⭐⭐⭐ 给整个 MoE 剪枝 / 可解释性社区敲了警钟——别拿群体观测统计去许诺 token 级干预结论
