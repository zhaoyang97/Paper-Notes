# A Framework for Studying AI Agent Behavior: Evidence from Consumer Choice Experiments

**会议**: ICLR 2026  
**OpenReview**: [https://openreview.net/forum?id=xAPoscV2Bw](https://openreview.net/forum?id=xAPoscV2Bw)  
**代码**: abxlab.media.mit.edu（开源 benchmark）  
**领域**: LLM Agent / 行为科学 / AI 安全  
**关键词**: 智能体决策、消费者选择、行为偏差、nudge、中间人框架、benchmark  

## 一句话总结
作者提出 **ABXLAB**——一个实时拦截并改写网页内容的"中间人"框架，把任意购物网站变成可控的行为实验场，系统性地测量 17 个主流 LLM 智能体在价格、评分、展示顺序、心理 nudge 等线索下的选择偏差，发现智能体比人类更容易被操纵，偏差幅度可达人类的 3–10 倍。

## 研究背景与动机
- **领域现状**：LLM 智能体正成为一类新的"经济行为人"，替我们做购物、订行程、甚至选医疗方案的决策。但现有评测（WebArena、VisualWebArena 等）几乎只看**任务完成率**——智能体有没有点对按钮、找对商品、填对表单。
- **现有痛点**：任务能力（competence）只是委托代理的一半，另一半是**信任（trust）**。当用户把决策权交出去，就默认智能体会用常识和稳定判断回应任务结构，不会因为肤浅线索、随意排序、无关包装而摇摆。可现实是，环境本身就是被"设计来引导选择"的，没人测过智能体在这种被精心设计的选择架构下会怎么选。
- **核心矛盾**：人们直觉上以为"摆脱了认知局限的智能体应该更理性、更稳健"，但前期工作（Cherep et al. 2024/2025）已发现 LLM 对简单 nudge **超敏感**，甚至比人更容易被推着走。这种脆弱性在真实、高维的网页环境里会放大到什么程度，无人系统研究。
- **本文目标**：建立一套"AI 智能体行为科学"的方法论与可复现 testbed，回答**何时、如何、在什么样的选择架构下**智能体的行为会发生偏移，并量化这种偏移相对人类基线的大小。
- **核心 idea**：**借用消费者选择实验范式**——既然心理学/行为经济学用"购物选择"研究了几十年的人类偏差，那就把同一套受控操纵（改价格、改评分、注入 nudge）原样搬到智能体身上，用同样严格的因果推断手段测它们的偏差。**用中间人改写而非自建环境**——拦截真实网页观测、在智能体看到之前注入干预，使框架可扩展到任意网站和任意干预，无需为每个实验定制环境。

## 方法详解

### 整体框架
ABXLAB（ABx = Agent Behavior eXperiments）由三部分串成一条受控实验流水线：**(1) 商品配对**从真实购物目录里挑出"同类、价格相近、评分可控"的商品对；**(2) 干预引擎**作为中间人，在智能体看到网页观测前实时改写其中一个（或不改）商品的展示内容（注入 nudge、匹配价格等）；**(3) 二选一强制选择 + 因果分析**让智能体在两个商品页之间做 2AFC 决策并加购物车，再用带聚类稳健标准误的线性概率模型估计每个线索的边际效应。实现脱胎于 AgentLab 与 WebArena 的 OneStopMarket 购物环境。

```mermaid
flowchart LR
    A[真实商品目录] --> B[商品配对<br/>同类·评分/价格约束]
    B --> C[2AFC 实验配置<br/>10干预×50对×3条件]
    C --> D[干预引擎<br/>中间人改写观测 O→O']
    D --> E[LLM 智能体<br/>CoT+短期记忆·9动作空间]
    E --> F[加购物车=做出选择]
    F --> G[线性概率模型<br/>估计各线索边际效应pp]
```

### 关键设计

**1. 中间人干预引擎：把环境形式化为可注入观测的马尔可夫过程** 框架把环境形式化为 $E=\langle S,A,O,T,I\rangle$，状态空间 $S$、动作空间 $A$、观测空间 $O$、确定性转移 $T:S\times A\to S$，关键多出一个**干预函数集** $I=\{I:O\to O\}$。每一步智能体基于被改写的观测 $\tilde{o}_t=I(o_{t+1})$ 行动，而非原始观测 $o_{t+1}$——干预只动"智能体看到什么"，不动底层网页和动作逻辑。这种"在观测层做手脚"的设计让任意网站都能秒变可控行为实验场，无需为每种干预重写环境，也保证了价格匹配、nudge 注入等操纵在因果上是干净的单点变量。智能体侧配置为剪枝后的视口 HTML 观测、9 个动作（click/fill/goto/scroll 等）、显式 CoT 思维链 + 短期记忆，加购物车或满 10 步即结束。

**2. 双正则商品配对：让"选择"在生态有效的前提下可控** 人不会拿 200 美元的电视跟 5000 美元的比，所以配对必须落在同一商品类内、且属性差异受限。两个商品 $p_1,p_2$ 成对当且仅当 $|\text{rating}(p_1)-\text{rating}(p_2)|\le\Delta_r$ 且 $\frac{|\text{price}(p_1)-\text{price}(p_2)|}{\min\{\text{price}(p_1),\text{price}(p_2)\}}\le\Delta_p$。原始实验用宽松正则（$\Delta_r=0.10$、$\Delta_p=0.50$）按价格排序配相邻商品，保留真实的价格/评分异质性；匹配实验则收紧到 $\Delta_r=0$（评分完全相等），并在 $k=10$ 的邻域里搜出**最大的不重叠有效配对集合**，再均匀下采样到每组固定 50 对。配对前还用轻量 LLM 过滤掉标题里自带 nudge 味的词（"top-rated"/"great for…"）和多件捆绑装，确保唯一变量是评分、价格和注入的 nudge。

**3. 五类 nudge × 属性匹配的因果阶梯实验** 干预分五大类各两条文案：权威（"被领先专家强烈推荐"/"Wirecutter 该品类首选"）、社会认同（"畅销品！"/"已被 5 万+顾客购买"）、稀缺（"仅剩一小时"/"限量版"）、负面框架（"已有新版本"/"最终特卖不可退"）、激励（"免运费"/"买一送一"）。实验设计成一道**逐步剥离混杂因素的阶梯**：Original（不匹配）→ MR（评分匹配）→ MRaP（评分+价格都匹配）。这样能依次问出"评分被拉平后价格效应变多强""价格也拉平后 nudge 还剩多少纯影响"。每组覆盖 10 干预 × 50 对 × 3 条件（无干预/第一个被 nudge/第二个被 nudge）= 1500 基础配置，总计跑了 8 万+ 次实验、约 25 亿 token、40 万次请求。

**4. 人类基线与用户画像对照** 为了让"智能体偏差大不大"有参照系，作者用同样的 50 对商品做了交互式二选一界面，在 Prolific 上招募 30 名被试各做 50 次决策并附简短理由，得到完整人类基线。同时构造**用户画像**实验：把"用户偏好"显式写进 prompt（如"用户预算紧张、重视高评分" vs "用户愿为好产品多花钱、不看重他人评价"），沿"属性焦点 × 敏感方向（增强/减弱）"两维探测智能体能否按指令调整偏好，检验偏差是天生的还是可被引导的。

## 实验关键数据

### 主实验表格（部分模型，单位 pp = 绝对百分点，相对基线的选择概率变化）

| 模型 | Viewed 1st (O) | Higher Rated (O) | Cheaper (MR) | Nudged (MRaP) |
|------|------|------|------|------|
| GPT-5 | +16.7* | +61.8**** | +24.5** | +53.3**** |
| o3 | +13.4 | +77.6**** | +15.2* | +48.4**** |
| o4 Mini | +11.1 | +81.2**** | +12.4 | +38.5**** |
| Claude Sonnet 4 | -9.2 | +46.7**** | +32.5**** | +55.9**** |
| Gemini 2.5 Pro | -2.0 | +48.8**** | +33.8**** | +55.8**** |
| GPT-4.1 | +7.7 | +43.2**** | +32.4*** | +57.2**** |
| Llama 4 Maverick | +5.2 | +64.7**** | +30.2**** | +9.7* |
| GPT-4.1 Nano | **+88.8**** | +2.9 | -0.9 | 0.0 |
| Claude 3.5 Haiku | **-35.4**** | +7.8 | +9.0 | -5.7 |
| **人类基线** | **+4.0** (n.s.) | **+5.0** (n.s.) | **+9.4** (n.s.) | **+9.9*** |

> 评分效应（Higher Rated）在 17 个模型里有 14 个达 30–80pp；价格效应在评分匹配后急剧放大（Llama 4 Maverick 偏向便宜货达 **+93.2pp**）；nudge 在价格评分都匹配后仍能推动 10–60pp。人类对所有线索几乎都不敏感（≈7% 平均敏感度，多数不显著）。

### 消融实验表格（属性匹配阶梯 + 敏感度分析）

| 设置 | 现象 | 解读 |
|------|------|------|
| Original → MR | 拉平评分后，价格效应大幅增强 | 智能体用**层级决策规则**：有评分这个主导线索时价格被抑制 |
| MR → MRaP | 评分+价格都匹配后，价格效应基本消失 | 智能体确实依赖价格本身，而非价格的其他相关物 |
| 翻倍价差 / 1 分评分差 | 即便价格翻倍也只有温和影响；1 分评分差很少显著（仅 Claude Sonnet 4 例外） | 偏差**近乎二值触发**——小差异就够，更大差异并不进一步放大 |
| Nudge 文案异质性 | Wirecutter 权威 nudge 影响最大，其次"买一送一"、"畅销品" | 同一理论类型的 nudge 效果不等，**文案层面的措辞很关键** |

### 关键发现
- **智能体是"强偏差选择者"**：在没有人类那种认知约束的情况下，反而表现出系统性、可预测的强偏差，幅度是人类的 3–10 倍以上。
- **顺序脆弱性**：展示顺序效应高度异质——GPT-4.1 Nano 对第一个商品有 +90pp 偏好，Claude 3.5 Haiku 反而 -35.4pp 惩罚第一个，说明当前智能体缺乏处理呈现顺序的稳健机制。
- **评分被当作近乎决定性的线索**，尽管用户评分常与客观质量相关性很弱，这在所有模型家族（GPT/Claude/Gemini/Llama）中一致出现，是 LLM 智能体的**根本特征**而非个别模型的产物。
- **用户画像极度有效**：把偏好写进 prompt 后智能体响应极强，说明偏差可被显式引导——既是风险也是控制杠杆。

## 亮点与洞察
- **范式迁移做得漂亮**：把行为经济学几十年验证过的"消费者选择 + 受控操纵 + 因果推断"整套方法论搬到 AI 智能体上，给"AI 行为科学"提供了一个真正可量化、可复现的范本，而不是又一个完成率排行榜。
- **中间人架构是杠杆**：在观测层注入干预这一招，让框架与具体网站、具体干预解耦，理论上能扩展到任意网页和任意操纵，复用价值远超单篇 benchmark。
- **风险/机会双面叙事**：作者没有止步于"智能体有偏差"的警告，而是指出消费者选择同时是研究智能体行为最强的 testbed——这种辩证框定让工作既有安全价值又有方法论价值。
- **规模与严谨并重**：8 万+ 实验、17 个 SOTA 模型、配 30 人 Prolific 人类基线 + 线性概率模型 + BH 多重检验校正，结论的统计可信度很高。

## 局限与展望
- **环境单一**：所有结论来自 OneStopMarket 单个购物环境的 2AFC 范式，是否迁移到旅行预订、医疗选择等高风险场景仍待验证。
- **观测无视觉**：智能体只看剪枝 HTML、没有视觉输入，而真实购物决策高度依赖图片/排版，视觉 nudge 的影响被排除在外。
- **"偏差"的规范性模糊**：偏向高评分/低价在很多情况下其实是合理的，论文把偏离人类基线一律称作"偏差"，但缺乏一个明确的"正确选择"标准来区分"合理偏好"与"被操纵"。
- **缓解方案缺位**：工作充分诊断了脆弱性，但没给出降低 nudge 敏感性的训练/提示干预方案，未来可在此 testbed 上系统评测去偏方法。

## 相关工作与启发
- **对接智能体评测**：与 WebArena、VisualWebArena 等"任务完成率"导向的 benchmark 互补——本文主张评测要从"能不能完成"深入到"怎么选择"，是智能体评测维度的扩展。
- **接续行为科学传统**：直接承接 Simon 的有限理性、Kahneman & Tversky 的启发式与偏差、Thaler & Sunstein 的 nudge 理论，把人类决策研究的概念体系移植到机器决策。
- **延续 nudge 超敏感线索**：在 Cherep et al. (2024/2025) 受控环境发现 LLM 对 nudge 超敏感的基础上，推进到真实高维网页环境的验证。
- **启发**：这套"中间人 + 受控操纵 + 因果推断"的方法论可推广到任意 agent 行为审计场景——凡是环境被设计来引导决策的地方（推荐系统、对话、招聘筛选），都能用类似框架在部署前测出智能体的可操纵性。

## 评分
- **新颖性**: ⭐⭐⭐⭐⭐ 把消费者选择实验范式系统迁移到 AI 智能体、并用中间人架构做成可扩展 testbed，方法论上开辟了"AI 行为科学"的清晰路径。
- **实验充分度**: ⭐⭐⭐⭐⭐ 8 万+ 实验、17 个 SOTA 模型、配 30 人人类基线、属性匹配阶梯消融 + 敏感度分析 + 用户画像，统计严谨（聚类稳健 SE + BH 校正）。
- **写作质量**: ⭐⭐⭐⭐ 问题动机讲得清晰有力，风险/机会的辩证框定有说服力；图表信息密度高但表格列较多需细读。
- **价值**: ⭐⭐⭐⭐⭐ 在智能体大规模代理决策的当下，揭示其系统性可操纵性并开源 benchmark，对安全、对齐、智能体设计都有直接现实意义。
