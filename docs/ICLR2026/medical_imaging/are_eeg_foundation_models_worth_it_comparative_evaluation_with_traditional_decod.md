# Are EEG Foundation Models Worth It? Comparative Evaluation with Traditional Decoders in Diverse BCI Tasks

**会议**: ICLR2026  
**OpenReview**: [https://openreview.net/forum?id=5Xwm8e6vbh](https://openreview.net/forum?id=5Xwm8e6vbh)  
**代码**: https://github.com/LiuyinYang1101/STEEGFormer  
**领域**: 医学图像 / EEG 脑信号解码 / 基础模型评测  
**关键词**: EEG 基础模型, BCI, 评测基准, 线性探测, 缩放律

## 一句话总结
作者在 7 个分类任务 + 2 个回归任务、6 种评测协议下对 5 个主流 EEG 基础模型做了带统计检验的系统对照，并提出一个只用掩码自编码（MAE）在 800 万段原始 EEG 上预训练的简单 ViT 基线 ST-EEGFormer，结论是：基础模型只在数据充足的群体级解码里有明显优势，在数据稀缺的个体级场景常常跑不赢紧凑的 CNN 甚至经典非神经网络解码器，线性探测普遍很弱，且看不到清晰的缩放律。

## 研究背景与动机
**领域现状**：EEG（脑电）是脑机接口（BCI）里最常用的无创信号，运动想象、ERP/P300、SSVEP 等范式各自支撑着外骨骼控制、注意力解码、高速拼写等应用。受 NLP/CV 基础模型启发，近两年涌现了一批"EEG 基础模型"——在大规模 EEG 上自监督预训练、再迁移到各下游任务，宣称能学到可泛化的通用神经表征，从而摆脱"每个任务从头训一个模型"的困境。

**现有痛点**：这些工作的"强性能"几乎都是在很有限的评测条件下报告的——通常只测一两种协议（如留一被试零样本、或群体解码），很少做统计显著性检验，更几乎不和经典的非神经网络解码器（CSP/FBCSP、黎曼几何分类器、FBCCA/TRCA 等）对比。而后者在数据受限场景里往往依然很能打。于是"基础模型到底值不值预训练/微调那一大笔算力"这个问题始终没有被诚实地回答。

**核心矛盾**：宣传里的优势来自**评测设置的选择性**（cherry-picked 任务 + 协议 + 缺统计检验），而非方法本身的稳健优越。预训练假设（复杂自监督目标 → 通用表征）和下游实证能力之间存在一道没人系统量化过的鸿沟。

**本文目标**：把这道鸿沟摊开测清楚——(1) 预训练后基础模型真的学到鲁棒表征了吗（线性探测能不能说明问题）？(2) 它们能否跑赢经典神经网络解码器？(3) 能否跑赢经典非神经网络解码器？(4) EEG 分类模型能迁移到回归吗？(5) 存在缩放律吗？

**切入角度**：不发明更强的模型，而是搭一个**公平、可复现、带严格统计检验**的多维基准，把基础模型、经典神经网络、经典非神经网络放在同一张评测网格里横向比；同时做一个"故意简单"的基础模型 ST-EEGFormer 当透明对照，用它来检验"复杂预训练目标是否必要"。

**核心 idea**：用一个六维评测框架 + 统计检验，把"EEG 基础模型值不值"这个被宣传裹挟的问题做成可证伪的实证结论，并用一个朴素 MAE 基线戳破"原始信号上 MAE 没用"的流行论断。

## 方法详解
这是一篇评测/分析向论文，"方法"主体是**评测协议设计 + 任务/模型矩阵**，外加一个作为透明对照基线的 ST-EEGFormer。下面先讲整体评测框架，再展开几个关键设计。

### 整体框架
作者把"评测一个 EEG 解码器"拆成两个正交维度：**用什么协议训练/测试**（6 种）× **在什么任务上**（7 分类 + 2 回归 + 2 个常规跨被试数据集）。每个被测模型（5 个基础模型的线性探测与微调两种用法、4 个经典神经网络、若干经典非神经网络）都在这张网格上跑一遍，得到准确率/AUC/Kappa/MSE/Pearson 等指标，再用 Wilcoxon 符号秩检验、置换检验、Mann–Whitney U 检验（均做 Bonferroni 校正）判断组间差异是否显著。所有数据集统一做 0.1–128 Hz 带通 + 256 Hz 重采样的最小预处理，分类任务多用被试内 5 折交叉验证（BCI-IV-2A、ERN 沿用比赛官方划分，TUEV/FACED 用 80/20 跨被试划分）。

六种评测协议刻画的是模型泛化能力的不同切面：

- **Population（群体解码）**：池化所有被试数据训一个模型，再分别测每个被试——衡量能否抓住跨个体的全局神经模式。
- **Per-Subject (Self)**：为每个被试单独训一个模型并在其自身上测——传统的"被试相关"BCI 做法。
- **Per-Subject (Transfer)**：被试 A 训的模型拿去测被试 B——个体模型的迁移性。
- **LOO Zero-Shot（留一被试零样本）**：群体模型在除 LOO 被试外的所有人上训，直接测 LOO 被试，不做任何适配。
- **LOO Fine-Tune**：上述群体模型再在 LOO 被试上做有限微调后测它——衡量"新被试快速适配"能力。
- **LOO Drop**：微调到新被试后，再回看群体被试的准确率掉了多少——量化灾难性遗忘 / 泛化损失。

### 关键设计

**1. 六维评测协议：把"泛化"拆成可分别检验的切面**

针对前面"只测一两种协议导致结论被美化"的痛点，作者把模糊的"泛化好不好"显式拆成 6 个可独立测量的协议（群体 / 个体自测 / 个体迁移 / 留一零样本 / 留一微调 / 留一遗忘）。关键在于这 6 个切面问的是不同的问题：群体解码考的是"有大量数据时能学到共性吗"，个体迁移和留一零样本考的是"表征能不能跨人搬"，而 LOO Drop 单独把"微调到新人后会不会忘掉群体知识"拎出来量化（类似灾难性遗忘）。正是这种拆分让结论变得可证伪——例如基础模型在 Population 上确实赢，但在 Per-Subject 这种低数据切面就不再显著，这种"分场景结论"是单协议评测永远看不到的。每个格子都配 Bonferroni 校正后的统计检验，避免把噪声当成性能差。

**2. 难度跨度极大的下游任务矩阵：暴露任务依赖性**

针对"基础模型论文常挑容易出彩的任务"的痛点，作者刻意选了 7 个**复杂度跨度极大且大多没被现有文献/预训练数据覆盖**的分类任务：从近乎二分类的 Error-ERN，到三类阿尔茨海默症诊断、四类内语音（inner speech）、四类运动想象 BCI-IV-2A、七类上肢运动执行 / 运动想象，一直到 40 目标双眼 SSVEP（含双眼交换刺激带来的复杂互调成分）这种极难任务；外加两个回归任务（DTU 听觉注意解码、SEED-VIG 警觉度预测）。除 BCI-IV-2A 被故意保留作"可识别基线"（且确实进了 ST-EEGFormer 的预训练）外，其余任务都不在被测基础模型的预训练数据里，从而能干净地测"真·迁移"。这套矩阵直接导出一个重要结论：简单任务（ERN）小模型就能逼近天花板（≈99.9%）、缩放毫无空间，难任务（内语音）则不管多大模型都几乎不涨——性能强烈依赖任务本身。

**3. ST-EEGFormer：一个"故意简单"的 MAE 基线，戳破复杂预训练神话**

LaBraM 等工作的流行论断是"在原始 EEG 上直接做 MAE 没用、必须先把信号离散成神经 token 再预训练"。作者用一个反例来反驳：ST-EEGFormer 就是一个 ViT，把输入 EEG 沿空间和时间维切成段，每段经线性投影成 token，并叠加时间位置编码（TPE）与空间位置编码（SPE）；随机掩掉 75% 的 token，编码器只处理可见 token，再把带位置编码的 mask token 与编码器输出拼回完整 token 集，送进一个小的 transformer + 线性投影解码器去重建原始 EEG 信号——纯粹的 MAE，没有任何花哨的预训练目标。预训练语料是 800 万+ 段原始 EEG。微调时只保留编码器。就是这么一个透明朴素的模型，它的大号变体 ST-EEGFormer-l 在多个协议里达到甚至超过最强经典神经网络（CTNet），证明"直接在原始信号上 MAE"完全能产出顶尖模型，复杂预训练目标在微调后带来的额外收益其实有限。

**4. 隐藏实现因素的拆解：把"不可比"的根因揪出来**

作者发现跨模型对比之所以常常不公平，根子在两个被普遍少报的下游设计选择。其一是**线性探测头的容量**：EEGPT 和 CBraMod 即便在号称"linear probing"的设置里也用了多层分类头，相当于偷偷加了容量，这很可能就是 EEGPT 线性探测异常强的原因——"线性探测"这个词掩盖了头部复杂度的巨大差异（附录显示更复杂的头能显著抬高线性探测精度）。其二是**token 融合策略**：CBraMod 把全部 token 喂给头，LaBraM 可选 class-token 或全 token 融合，ST-EEGFormer 默认用 ViT 式的平均 token 融合——这些选择改变了送进分类头的有效感受野与信息量，即便骨干和数据固定，简单融合+单层线性头通常打不过更表达力强的头。结论是：头深度/宽度、融合方案这些"看似不起眼的细节"足以制造巨大性能差，因此呼吁未来工作必须显式报告头结构与融合策略，并采用统一的报告清单来标准化线性探测 vs 微调协议。

## 实验关键数据

### 主实验（分组横向对比）
作者用"跨指标/被试/数据集/协议聚合的平均排名"（越低越好）来比较各组解码器，核心发现如下：

| 对比问题 | 关键结论 |
|----------|----------|
| 预训练表征鲁棒吗（线性探测 vs 微调） | 除 EEGPT 外，微调普遍优于线性探测；线性探测在几乎所有协议上一致地弱（LOO Drop 除外） |
| 基础模型 vs 经典神经网络 | 经典 NN（尤其 CTNet）在多数协议上稳定压过所有线性探测的基础模型；只有最大的全量微调 ST-EEGFormer-l 能达到或超过最强经典 NN |
| 基础模型 vs 经典非神经网络 | 微调后的基础模型（尤其 ST-EEGFormer-l）总体取得最高或相当的性能；但在 Per-Subject (Self) 等低数据协议，经典非 NN 与之无显著差异 |
| 是否存在缩放律 | 跨架构看"越大越好"不成立（归一化精度对模型大小的对数拟合很差）；但训练时间随模型大小指数增长（$R^2=0.60$） |

群体解码（Population）是基础模型最占优的场景：微调基础模型和 ST-EEGFormer-l 取得最高精度且两者无显著差异，并显著优于经典 NN 与非 NN；但到了 Per-Subject 这种低数据切面，优势就消失了。

### 回归与缩放（消融/分析表）
LOO Zero-Shot 协议下两个回归数据集的表现，揭示"分类→回归"迁移并不稳健：

| 数据集 | 最佳模型 | Pearson R | 现象 |
|--------|----------|-----------|------|
| DTU（听觉注意，1s 片段） | CTNet / 线性探测 EEGPT | ≈0.05 | 经典解码器与线性探测基础模型反而优于**微调**基础模型 |
| SEED-VIG（警觉度，5s 片段） | EEGNet / DeepConvNet | >0.45 | 经典 NN 领先，但与基础模型变体差异不显著 |

值得注意的是多个微调基础模型（BIOT(f)、BENDR(f)、LaBraM(f)、CBraMod(f)）在 DTU 上 MSE 反而劣化到 >1.3，Pearson 接近 0，说明微调的表征对回归任务并不通用。

### 关键发现
- **基础模型不是万能药**：只在数据充足的群体级设置里有清晰优势；数据稀缺时紧凑 CNN（CTNet）甚至经典非神经网络都能打平。
- **线性探测一致地弱且高度任务相关**：唯一例外是 ERN 检测，所有线性探测基础模型都表现不错，说明预训练特征的有用程度强烈依赖具体范式。
- **微调会"抹掉"大部分预训练差异**：注意力可视化显示微调后关注区域大幅改变；这也解释了为什么简单 MAE 的 ST-EEGFormer 微调后能追平复杂预训练模型——微调把简单 vs 复杂预训练之间的差距磨平了。
- **缩放的代价不对称**：精度随规模只微弱上升，算力/训练时间却指数上升；下游 BCI 数据集大多 <50 被试，是限制大模型收益的主因（类比 sEMG：<50 被试时错误率 >40%，>6000 被试时 <10%）。
- **LOO Drop 上经典 NN 反而最差**：微调到新被试后经典 NN 的群体性能掉得最狠，遗忘最严重——这是基础模型为数不多稳定占优的协议。

## 亮点与洞察
- **把"值不值"做成可证伪命题**：六维协议 × 难度跨度极大的任务矩阵 × 统计检验，第一次让"EEG 基础模型优势"这种被宣传裹挟的说法有了能被推翻的实证形态——这套评测设计本身比任何单个模型更有价值。
- **用反例打掉一个流行假设**：LaBraM 声称原始信号上 MAE 无效，作者用一个纯 MAE 的 ViT 基线直接做出顶尖性能，干净利落地证伪，且顺带说明"复杂预训练目标在微调后收益有限"。
- **揪出"线性探测"这个被滥用的词**：指出有些工作在号称 linear probing 时偷偷用多层头，这种隐藏容量让跨模型对比失真——这个观察可直接迁移到任何自监督表征评测里，提醒大家先对齐分类头再比骨干。
- **诚实地报告负结果**："大基础模型只追平小经典模型"被作者明确当作 benchmark 级结论而非调参失误来报告，强调在算力代价下这种"打平"几乎没有实用价值。

## 局限与展望
- **作者承认的局限**：当前 EEG 基础模型生态高度碎片化（预训练策略、评测协议、报告习惯各不相同），下游数据集普遍又小又少（<50 被试），导致大规模缩放分析根本做不起来——这既是被测对象的局限，也限制了本文结论的外推。
- **缺一个 EEG 版 ImageNet**：很多结论（看不到缩放律、低数据下优势消失）很可能是数据稀缺的产物而非方法上限，作者反复呼吁社区共建大规模标准化 EEG 数据集，但本文无法替代这件事。
- **回归只测了两个数据集**：分类→回归的迁移结论建立在 DTU、SEED-VIG 两个数据集上，样本偏少；DTU 上所有模型 R 都低到 ≈0.05，任务本身难度可能掩盖了模型差异。
- **改进思路**：在统一大数据集上重做缩放实验、把"报告清单（头结构 + 融合策略 + 线性探测/微调协议）"做成社区标准、并把六维协议扩展到更多生理信号模态（如 sEMG、fNIRS）以检验结论的跨模态稳健性。

## 相关工作与启发
- **vs LaBraM**: LaBraM 主张原始 EEG 上 MAE 无效、需先做神经 token 离散化；本文用纯 MAE 的 ST-EEGFormer 反例证明直接 MAE 也能顶尖，差异在于"是否相信复杂预训练目标的必要性"，本文站在"简单透明也够用"一侧。
- **vs EEGPT / CBraMod**: 它们以更强的下游头（多层 / 全 token 融合）取得亮眼线性探测结果；本文指出这其实是头部容量在起作用而非骨干表征更优，提醒读者把"线性探测"的实现对齐后再下结论。
- **vs 经典解码器（CSP/FBCSP、黎曼分类器、FBCCA/TRCA）**: 既有基础模型工作几乎不与它们对比；本文把它们拉进同一基准，证明在数据稀缺协议下这些被忽视的简单基线常常与基础模型打平，凸显"别低估经典基线"。
- **vs 单协议基础模型评测**: 过往多用留一零样本或群体解码单协议 + 无统计检验；本文用六维协议 + 严格显著性检验，把"选择性评测带来的乐观结论"系统性地纠偏。

## 评分
- 新颖性: ⭐⭐⭐⭐ 不是新模型而是新评测范式，但六维协议 + 反例基线的组合在 EEG 领域确属首个系统性诚实基准
- 实验充分度: ⭐⭐⭐⭐⭐ 5 基础模型 ×2 用法 + 4 经典 NN + 一堆经典非 NN，跨 9 任务 ×6 协议、全程统计检验，工作量极大
- 写作质量: ⭐⭐⭐⭐ 结构清晰、结论诚实，但大量结果压在附录、正文图依赖度高
- 价值: ⭐⭐⭐⭐⭐ 给被宣传裹挟的 EEG 基础模型领域提供了一面照妖镜和一套可复现的评测规范，并开源全部代码与模型
